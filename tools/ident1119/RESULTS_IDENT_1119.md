## 0. 結論 (先に)

* **事前に依頼した試験 (a)〜(d) は、どれも設計された形では入っていない**。収録されているのはすべてジョイスティックによる自由走行 (速度上限の設定 4.0/5.0/5.5/6.0)。指令の最大は 6.00 m/s で、**6.0 を超える指令は 1 度も出ていない**。往復の長い直線も、定常円も、操舵の単独ステップも無い。
* 最高速度: 指令 6.0 で車輪速 5.96 m/s (1 s 平均)、定常ゲイン 0.993。**飽和の兆候は 6.0 までは無い** (10/31 の「6.0 設定で K=0.959」は今回は再現せず 0.99)。最高速度の上限は今回も決まらない (≥ 6.0)。
* **舵角制限則の a_lim は 3.0 m/s² (推定 2.988、6 bag・11 226 点)。10/31 の 3.5 から変わっている**。今回の旋回は a_cmd ≤ 3.0 に制限されており、定常旋回の実 a_y は 2.2〜3.1 m/s² までしか出ていない。10/31 の「右 4.8」は超えていない。**横加速度の上限は今回も決まらない**。
* 例外: 手動 102621 の 9〜11.5 s に、指令舵角 ≤ 5° (d0 = 4→0°) で IMU ヨーレート 1.5 rad/s (速度 5.3 m/s) の左回りの暴れが出た。v·gz = 7.7 m/s² (1 s 平均)、IMU 横加速度 5.6〜6.7 m/s²、VN の横速度 0.7 m/s (横滑り角約 9°)、ロールは 2° 未満。制御不能な事象で定常旋回ではないが、**この車両は 6 m/s² 超の横加速度を少なくとも一時的に出す**。原因は未特定 (§6.3)。
* 並進速度の応答: **計画機の出力 (can_tx の rpm 指令) が記録されていた**ことで、10/31 では「再現」していた計画機を直接入力にできた。むだ時間は ≤ 0.02 s (0 に張り付き)、一次遅れ T = 0.30〜0.33 s、K = 0.986。10/31 の T = 0.21 は勾配制限 a_acc = 3.95 を自由にした別構造のモデルの値で、計画機 5.0 固定の T = 0.34 とは整合する (§4)。
* 加速度の速度依存 (中央値 3.76 − 0.31v) は 10/31 (4.36 − 0.39v) と整合。v = 5〜5.5 で 2.1 m/s²。減速は計画機の勾配制限を通らない停止で 4.65 m/s から 1.05 s で停止 (ピーク −6.9、10-90 % 平均 −4.45 m/s²、1 事象のみ)。

* むだ時間 L は d1 でも等価舵角でも 5 % 以内の範囲が 0〜0.1 s と広く、**今回も決まらない**。

## 6. 横加速度の限界 (`s4_lateral.py`, `s4b_events.py`; `out/s4_sections.csv`, `s4_summary.csv`, `s4_window_max.csv`, `s4b_high_lat_events.csv`)

### 6.1 ヨーレートの推定法の妥当性 (chassis_only には IMU が無い)

3 通りで a_y (左向き正) を求めた: (1) a_geo = v² tan(d1)/L (従動輪の実舵角、全 bag)、(2) a_kin_wheel = v·c·(vR − vL)/0.6 (輪速差。c は IMU のある 2 bag で較正)、(3) a_kin_imu = v·gz (IMU のある区間のみ)。

* 輪速差と IMU (0.25 s 平滑、v > 1): **c = 0.796** (102621: 0.789、102800: 0.818、相関 0.71〜0.91)。chassis_driver の yaw_rate_ratio 0.72 より大きい (有効トレッド 0.6/0.796 = 0.75 m、設定 0.83 m)。相関が低いのは、輪速差が 5 Hz 付近で ±1 rad/s の振動を持つため (§6.3 の図)。**輪速差のヨーレートは ±10 % 以上の不確かさがあり、定常区間の平均でのみ使える**。
* 従動輪角の幾何と IMU: 相関 0.986〜0.996 と高いが、比は 102621 で 0.79、102800 で 1.01 とばらつく (102621 は暴れの区間を含み、d1 > 実際の旋回)。a_geo は IMU との比 0.8〜1.0 の幅を持つ。
* IMU の無い 4 bag の a_y は、**a_geo と a_kin_wheel の 2 値の幅**として示す。a_y の絶対値は ±15 % 程度とみなす。左右の比較は同じ推定法どうしなら c が共通なので頑健。

### 6.2 定常旋回区間 (1.0 s 以上、|d0| > 2°、速度 ≥ 2 m/s で速度の幅 ≤ 20 %、先頭 0.5 s を除く) 計 19 区間

|---|---|---|---|---|---|---|---|---|
| 左 | 9 / 21.5 s | 4.01 | 2.97 | 2.69 / 3.13 | 2.25 / 2.64 | — | 0.84 | 0.99 |
| 右 | 10 / 18.5 s | 4.57 | 2.97 | 2.53 / 3.04 | 2.43 / 2.88 | 1.39 / 2.01 (2 区間) | 0.91 (chassis_only 0.93) | 0.94 (0.97) |

### 6.3 事象: 102621 の 9〜11.5 s (`figs/ident1119_spin_event.png`, `out/s4b_high_lat_events.csv`)

速度 5.3 m/s、指令舵角 +6° → 0° (d0 = 4° → 0°) の直進に近い指令で、**IMU ヨーレートが 0.7 → 1.6 rad/s に増え (指令からの運動学値の約 3 倍)**、従動輪角は 17°まで開いた。v·gz = 7.7 m/s² (1 s 平均)、IMU 横加速度 (−acc.x) 5.6 (1 s 平均) 〜 6.7 m/s²、VN の横速度 vy = 0.7〜0.75 m/s (横滑り角約 9°)、ロール 1.8° 未満、速度は 5.3 → 4.4 m/s。11.3 s に操作者が −15° に切り返し、右旋回へ移った。同じ区間で輪速差のヨーレートは ±1 rad/s で振動し (vR − vL が 5 Hz 付近で振れる)、実際の旋回と逆向きの平均を示す。**操舵制御が効かず、車体が輪速差の指令と無関係に左へ回った**。原因 (路面の傾斜・駆動輪の空転・従動輪のシミー・IMU の暴走など) は今回のデータから特定できない。VN の横速度と IMU の横加速度の両方が同方向に大きいので、IMU の誤動作ではなく実際の運動と判断するが、**定常旋回ではなく、横加速度の限界の根拠としては使えない**。ただし「5.3 m/s で 6〜7 m/s² の横加速度でも転倒しなかった」ことは確認できる (ロール < 2°)。

## 9. 確度の低い推定の一覧

1. 輪速差ヨーレートの係数 c = 0.796 (IMU 2 bag・計 3 296 点から)。bag 間 0.79〜0.82、相関 0.71〜0.91。chassis_only の a_kin_wheel と eq_wheel の K はこの値に依存する。
2. IMU の gz バイアス補正: 102800 の VN 欠落後 (17.5 s〜) は停止後 (52〜70 s) の平均 0.194 rad/s、102957 は開始時の停止区間 (1.4〜2.6 s) の 0.186 rad/s を引いた (バイアスが一定という仮定)。102621 のバイアスは 0.001。
3. 計画機入力の当てはめの a_dec = 10 m/s² は上限に張り付いた不定値 (制動が計画機の 5.0 で決まる)。a_acc 4.3 は bag 別に 3.6〜6.6 で、a_acc と T は相関する。
4. 加速度の速度依存の 5.5 m/s 超 (6 m/s の 1.9〜2.5) は外挿 (5.0〜5.5 m/s は 52 サンプル)。
5. 勾配制限なしの停止 (ピーク −6.9、持続 −4.45 m/s²) は 1 事象。
6. 等価舵角 (IMU) の応答 (102800 約 38 s、102957 3.7 s) は 1〜2 bag。102621 の d1/eq の当てはめは暴れの区間を含み外れ値で除外。
7. 直進の偏りの前進/後進の比較: 後進は 164745 の 2 窓 2.9 s のみ。IMU の等価舵角は 3 窓 (4.4 s、102800)。
8. 102621 の事象 (§6.3): 原因不明。a_y = 7.7 は IMU の v·gz で、横方向の滑りを含む量 (IMU 横加速度は 5.6〜6.7)。
9. 車輪半径 0.1265 m (10/31 から踏襲): 速度の K と最高速度 [m/s] の絶対値は半径の選び方で ±2 % 動く。
10. 計画機 (can_tx) の速度換算は dell_ws の yaml の wheel_radius = 0.124 の仮定 (実機の値は未確認。a_lim の推定値 2.988 ≈ 3.0 がこの換算と整合するので妥当と判断)。
