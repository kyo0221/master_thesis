# ラップタイム内訳 (decomp)

T_lap = T_phys + ΔT_cap + ΔT_path + ΔT_plan + ΔT_track + ΔT_stop + ΔT_res　(T_ref = T_phys + ΔT_cap)。単位 s、符号付き (+ は時間の増加)。

- T_phys: 走行軌跡に物理限界 (v≤6.0 m/s [従動輪シミー限界], a_acc=3.4, a_dec=3.6 m/s², a_y,max=6.0) のみを与えて前方・後方走査した所要時間
- T_ref : T_phys に ソフトウェア上限 v_cap (R2 4.0, B1 4.5, R8 4.0, 10/12 4.0 m/s) を加えた所要時間。ΔT_cap = T_ref − T_phys
- ΔT_plan = T_plan,driven − T_ref (T_plan,driven: a_y=3.0, a_x=3.0 [10/12 は記録上 6.0], v_cap)
- ΔT_path = T_plan,rec − T_plan,driven (T_plan,rec: speed_path の 0.3 s プレビュー点の速度, 停止窓は窓直前の計画速度 v_b で置換)
- ΔT_track = 実経過時間 − T_plan,rec (停止窓を除く)。ΔT_stop = 窓の実経過時間 − 窓内距離/v_b。ΔT_res = T_lap − Σ。
