# 実車 2 本 (R1, B1) のラップタイム内訳と走行統計

> **物理限界の値**: 上限速度 6.0 m/s、加速 4.0 m/s² (車両試験の同定値 3.95、3.4 から変更)、減速 4.0 m/s² (同定値 4.06、3.6 から変更)、横加速度 6.0 m/s²。加速と減速は車両試験の同定値。上限速度 6.0 m/s と横加速度 6.0 m/s² は暫定で、T_phys と ΔT_cap はこれらの値に依存する (§6.5)。

論文転記用。日付は書かない。すべて `tools/decomp/` のスクリプトから生成 (`results_1027.py`)。速度・走行距離は、同定で採用した車輪半径 **0.1265 m** で換算した値 (記録の速度は設定値 0.124 m での換算なので ×1.0202)。設定値 0.124 m での換算は §7 に感度として残す。

## 0. 対象と定義

| 記号 | コース | 上限速度 | 抽出済み pkl (記録名。論文には書かない) | 備考 |
|---|---|---|---|---|
| R1 | 赤 | 4.0 m/s | 4ms_blue.pkl (名前は blue だが赤コース) | 信号停止 3 回 |
| B1 | 青 | 4.5 m/s | 4_ms_blue.pkl | 分岐 (交差点) を 3 周通過。自律区間は 181.19 s で打切り (第 3 周は部分周)。信号停止の記録なし |

- **解析範囲 (以下「自律区間」)**: 自律開始 ta → 3 周目の GNSS 基準線通過 (B1 は 3 周目の基準線の手前で /autonomous=False となった時刻 181.19 s)。時刻は記録の最初のメッセージを 0 とする。
- **周・ラップタイム**: 基準線 = 自律開始点を通り、開始後 3〜12 m の進行方向に直交する直線。GNSS (20 Hz 前後) の軌跡が基準線を通過した時刻を線形補間し、通過時刻の差をラップタイムとする。第 1 周は静止発進を含む。
- **走行距離**: 換算後の車輪速 (0.01 s 格子へ平均) の積分。**周長**: 完走した周 (基準線通過で区切った周) の車輪速積算距離の平均。**周回数** = 走行距離 / 周長。
- **実測速度・走行距離**: /chassis/velocity_body に ×1.0202 (車輪半径 0.1265 m / 0.124 m) を掛けたもの。**横偏差**: /planner/global_path (平滑化後の経路, base_link) の x=0 での y。経路生成の出力が基準であり、コースに対する独立な基準ではない。
- **舵角指令の絶対変化率**: /cmd_vel の steering_angle の連続 2 メッセージ間の |Δδ| / 0.05 s の平均 (制御周期 20 Hz 固定。記録のタイムスタンプは塊で届き Δt が 1e-4 s の対があるため Δt は使わない。欠落で Δt>0.25 s の対は除く)。
- **従来定義** (旧 Table runs と同じ): 自律 (手動でない) かつ 実測速度>3.5 m/s かつ 速度指令>3 m/s のサンプルだけを使う (停止・発進・低速を除く)。
- **信号停止の窓** (decomp_lib.stop_windows): 最初の stop_point 発行 → 最後の発行の 1.0 s 後以降に v_meas (0.3 s 移動平均) が窓直前の計画速度 v_b (窓開始前 2.0〜0.3 s の v_plan,rec の中央値) の 0.95 倍へ戻るまで。窓の間隔が 3 s 以内なら統合、継続 0.5 s 未満は除外。**保持時間** = 窓内で v_meas < 0.5 m/s の時間。
- **内訳の定義** (符号付き, 単位 s, + は時間の増加。T_lap = 実経過時間。恒等的に ΔT_res = 0):
  - T_phys: 走行軌跡に物理限界 (v ≤ 6.0 m/s [従動輪シミー限界], **加速 4.0, 減速 4.0 m/s²** [車両試験の同定値 3.95, 4.06], 横加速度 6.0 m/s²; 上限速度と横加速度は暫定) だけを与え、前方・後方走査した所要時間
  - ΔT_cap = T_ref − T_phys (T_ref: T_phys に上限速度 v_cap を加えた所要時間。同じ加減速・横加速度の限界を使う)
  - ΔT_plan = T_plan,driven − T_ref (T_plan,driven: 横加速度 3.0, 縦加速度 3.0 m/s², v_cap の速度計画)
  - ΔT_path = T_plan,rec − T_plan,driven (T_plan,rec: 記録された /planner/speed_path の 0.3 s 先の参照点の速度から求めた時間。停止窓内は v_b で置換)
  - ΔT_track = 実経過時間 − T_plan,rec (停止窓を除く)。ΔT_stop = 窓の実経過時間 − 窓内距離 / v_b
  - 曲率 κ = ω_z / v (VectorNav IMU の角速度 / 車輪速) を走行距離 0.1 m 格子へ補間し σ=1.0 m でガウス平滑。**カーブ** = σ=1.5 m 平滑後の |κ| > 0.04 1/m、それ以外は直線。
  - 速度計画の設定 (横加速度 3.0, 縦加速度 3.0, 上限 4.0/4.5 m/s) は従来のまま。

## 12. 未解決事項・注意

1. **物理限界のうち上限速度と横加速度は暫定**: 加速 4.0 m/s² (同定値 3.95)・減速 4.0 m/s² (同定値 4.06) は車両試験の同定値。減速 4.0 m/s² への変更は結果に影響しない (§6.6)。T_phys と ΔT_cap を決めるのは上限速度 6.0 m/s、加速 4.0 m/s² (発進・再発進区間, §6.7)、横加速度 6.0 m/s² (B1 の交差点カーブ) で、上限速度と横加速度が更新されると動く。上限速度 5.5 / 6.0 / 6.5 と横加速度 4 / 5 / 6 の感度は §6.5。
2. **車輪半径は同定値 0.1265 m に統一した** (距離・速度 = 記録値 ×1.0202)。0.124 m 換算は §7 に感度として残した。`decomp_cap_fraction.md` も同じ換算で、他の表と整合する。
3. B1 の GNSS 生の経路長は自律開始点付近のジグザグで 4 m 長い。周長・平面図は平滑後/解析範囲で扱った。
4. B1 の第 3 周は部分周 (周長の 97.5%, 58.42 s)。ラップタイムの比較には第 1, 2 周 (60.54, 59.75 s) を使う。基準線通過までの 60.86 s は手動制動中で参考値。
5. 横偏差の基準は経路生成の出力 (平滑化後の経路) であり、コースに対する独立な基準ではない。時系列図の横偏差は x=0 での y で、経路が自車より前から始まるフレーム (x の最小値>1.5 m) は欠測 (0.1% 以下)。
6. 解析ツールが読む pkl (`LP` 環境変数、既定は別セッションの scratchpad) は一時領域にある。再現にはその pkl が必要 (`tools/sil/data/lp/win.pkl` は切り出しで、ここでは使えない)。
7. 旧 R1 (chassis の走行) は車体応答が他と異なるため除外した。ツール (RUNS)・図・表から外し、旧 R2 を R1 に改名した。旧図 (decomp_4ms.png, decomp_4ms_r1265.png, decomp_timeseries.png, decomp_timeseries_B1.png, run4_timeseries.png, run1027_topdown.png, run1027_summary.png) は触っていない。論文 tex の参照差し替えは別担当。
