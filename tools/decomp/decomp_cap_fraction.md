# v_cap 支配率と T_phys の物理上限速度依存 (車輪半径 0.1265 m 較正後)

- v_ref は T_ref の速度プロファイル (v_cap, a_acc 4.0, a_dec 4.0, a_y,max 6.0)。v_rec は speed_path の 0.3 s プレビュー点の速度 (20 Hz 制御周期ごと、走行距離で重み付け)。
- 割合は解析範囲 (打切りまで) の走行距離に対する %。v_ref の「v_cap に等しい」は v_ref ≥ v_cap − 1e-6 m/s (曲率・加減速のどちらにも抑えられていない)。
- v_rec の割合は、全距離 (停止窓内を含む) と、停止窓を除いた距離の 2 通り。
