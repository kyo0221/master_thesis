{{ay}}

- v·ω: 車輪速 (×1.0202) × VectorNav IMU の yaw rate。IMU 横加速度: **この車両の IMU は x 軸が横方向** (v·ω との 1 s 移動平均の相関 0.72〜0.88、傾き 0.93〜1.08、y 軸の相関は 0)。静止直進部の中央値でバイアス除去して符号を反転した。生の IMU は 20 Hz で振動雑音が大きい (1 s 平均でも 4〜5.5 m/s² の最大が出るが、ロール・路面段差の混入と推測。v·ω の最大より過大)。

- **MPC の縦 PID の積分項による低速接近 (シミュレーションの予測)**: SIL の予測は「減速中の実速度が計画より平均 0.24 m/s 遅れ、計画速度が 0 になる時点で積分項 k_i I が平均 0.38 m/s² に達し、0.2 m/s 以下の低速接近が約 7.7 s、停止の ΔT_stop が 1 回 14.7 s」。実車 (4 m/s, 3 回): 実速度の遅れ 0.29〜0.35 m/s (予測 0.24)、計画速度が 0 になる時点の積分項 (`acceleration_i`) **0.49〜0.50 m/s²** (予測 0.38。実車では ±0.5 でクリップされている)。**積分項による低速接近は実車でも出ている**: v<0.5 m/s になってから車輪速の読みが 0 になるまで 2.5 / 3.1 / 3.8 s (平均 3.1 s)、その間 0.25〜0.38 m/s で進み、指令速度は積分項で 0.39 → 0.28 m/s と緩やかに減衰する (図 fig_stop_wave)。ただし **SIL の 7.7 s より短い** (差 約 4.6 s)。原因 (推測、赤 4 m/s の 1 回目の `/control/diagnostic` で確認): 車輪速のエンコーダが約 0.27 m/s (20 rpm) 以下で 0 を返し (読みは 0.14 / 0.27 / 0.28 / 0.305 の離散値)、速度が 0 と読まれた瞬間に制御器が積分項と速度指令を 0 にリセットする。SIL にはこの不感帯と reset がない。
- **ΔT_stop**: 実車 MPC は 11.1 / 11.8 / 11.8 s (平均 11.6、4 m/s) で、SIL (MPC 距離誤差あり) の 14.7 s より 3.1 s 短く、距離誤差なし (7.9 s) より長い。窓の局面 (平均): 減速 4.6 s + 低速接近 3.1 s + 停止保持 6.7 s + 再発進〜窓端 2.3 s = 窓 16.6 s。SIL の保持は 3 s 前後なので、実車の保持 6.7 s は信号の表示時間による。**1027 の R1 (Pure Pursuit) の ΔT_stop は 6.4 / 11.9 / 4.0 s (保持時間 3.1 / 9.7 / 2.7 s)** で、保持時間の違いが大きく、MPC と Pure Pursuit の差を直接は比べられない。
- **再発進**: 最後の stop_point 発行 (信号が緑に変わり停止点が消える) から v>0.5 m/s まで 0.8〜0.9 s (R-4 の 3 回目は最後が途中の短い発行のため除外)、緑パネルの最初の検出から v>0.5 m/s まで 0.76〜0.85 s (論文の R1: 約 0.7 s)。再発進の加速は a_x,max=3.0 m/s² の指令で、窓端 (計画速度の 95%) まで 1.5〜2.6 s (R-4 の 3 回目は窓が短い発行で延びて 3.8 s)。
- 5, 6 m/s では d0 が短く強い減速になるため低速接近は約 1 s と短い (計画速度が 0 になる時点の積分項は 5 m/s で +0.14〜+0.39、6 m/s で −0.23〜−0.25 m/s²)。ΔT_stop は 10.1 / 11.4 s と 4 m/s と同程度。
