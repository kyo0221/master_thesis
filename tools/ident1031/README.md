### 1.1 足回りの実装 (読み取り専用で確認: `/home/kyo/dell_ws/src/chassis_driver/chassis_driver/src/chassis_driver_node.cpp`, `velplanner.cpp`)

* `/cmd_vel` の速度 → **速度計画 `linear_planner`** (一定加速度 `linear_max.acc` = 5.0 m/s² で目標へ向かう計画。指令が来るたびに現在値から計画し直す) → `linear_vel`。`/cmd_vel` の舵角は ±15° にクリップして `cmd_steering`。
* 目標舵角 `delta`: |linear_vel| > 0.1 のとき `steering_max = min(atan(lateral_acc_max·wheelbase / linear_vel²), 15°)`、`delta = clip(cmd_steering, ±steering_max)`。それ以外は 0。`lateral_acc_max` は車両側で 3.5 m/s² (リポジトリの yaml は 3.0)。
* `caster_data = {delta, caster_orientation, caster_rotation}`: **d0 = delta、d1 = 従動輪の実測角 (エンコーダ、直進オフセット補正済み)**。
* 駆動輪: `angular_ff = linear_vel·tan(delta)/(wheelbase·0.72)` + `angular_fb = linear_vel·PID(delta − caster_filtered)` (caster は τ = 30 ms のローパス) → 左右輪の速度 ((∓tread·ω + 2v)/(2R))。
* したがって: 速度指令の応答 = 計画機 (±5.0 m/s²) → モータ制御 → 車輪。**制限則・d0 の再現は計画機の速度で行う** (本ツールは指令速度を 5.0 m/s² で追従させた値 `planner_vel` を使う。初期値 0)。

### 2.3 モデル比較

**結論**:
1. **足回りは「勾配制限 + 一次遅れ」で表される**。M1 (FOPDT) は RMSE 0.620 m/s で、勾配のあるランプを一次遅れで真似るために T = 1.24 s、K = 1.09 という非現実的な値へ逃げる。M2 は 0.135 (4.6 倍小さい)、a_acc 3.95、a_dec 4.06 m/s²、T 0.21 s、K 0.965、L = 0。図 `images/ident_step_speed.png` (5 m/s 設定の 54〜68 s) で FOPDT (点線) は制動・再加速で大きく外れ、M2 (破線) は重なる。
2. **計画機の 5.0 m/s² だけでは説明しきれない部分がある**: M2p (5.0 固定、T = 0.339) の RMSE は 0.153 で M2 より 13 % 悪く、**制動で 0.169 vs 0.092 と明確に悪い** (加速では 0.145 vs 0.152 でほぼ同じ)。制動の勾配は計画機でなく車輪側で ≈4 m/s² に制限される。加速は M2 と M2p が同等で、車輪側の制限の有無は M1〜M2 の比較だけでは断定できないが、速度依存モデル M3 が 0.117 (全体)・0.132 (加速) と最良で、a_acc(v) = 4.36 − 0.39v → 4 m/s で 2.8、6 m/s で 2.0 m/s²。制動側の速度依存は弱い (4.24 − 0.11v)。
3. 「持続的な勾配はピークより小さい」: ピークは 4.7〜5.0 に達する (計画機の上限 5.0 とほぼ一致) が、10→90 % 平均は加速 3.0、制動 3.6、モデルの勾配は 4.0 前後 (M2) で、5.0 を下回る。**モータ側の制限で勾配が 5.0 より小さい**という解釈と整合する (速度が高いほど顕著)。ただし M2p との差は小さく、T = 0.34 s の一次遅れと車輪側の勾配制限の分離は今回のデータでは確実でない (推測)。
4. L は M2、M3、M2p とも 0 (下限) で、むだ時間は同定できない。

* a_geo は左右とも大きい (3.1〜5.4)。d1 は左右対称で、**d1 が d0 を超える**: 5 m/s の右旋回で d0 5.9° に対し d1 7.3〜9.0°、左旋回で 7.4〜7.9° (K_d1 ≈ 1.3)。幾何から見ると左でも 4.2〜4.5 m/s² だが、実際のヨーは左では小さい。滑り指標 (旋回方向正) は左 −1.5〜−3.5°、右 −1.1〜+2.3°。
* **高速の右旋回では駆動輪の左右速度差が実際のヨーより小さい**: 5〜5.7 m/s の右旋回で (右輪−左輪)/トレッド = −0.18〜−0.58 rad/s に対し gz = −0.80〜−0.92 rad/s (5.7 m/s では −0.18 vs −0.90)。左旋回は全速度で両者がほぼ一致 (比 0.9〜1.4)、右旋回も 3〜4.5 m/s では一致 (−0.70〜−1.40 vs −0.72〜−1.18)。高速の右旋回ではヨーがキャスタ角 (d1) 側で決まり、駆動輪の速度差は小さい。原因は未確認 (推測: 従動輪のステア機構の挙動、タイヤの横滑り)。
* ロール (車両) は標準偏差 0.9〜1.2°、95 %点 1.5〜2.0°。**横加速度とほとんど相関しない** (|r| ≤ 0.23、傾き ≤ 0.09°/(m/s²))。ロール振れ ≤ 2° の条件はほぼ常に満たされ、実質的な制約は滑り指標 (|δ_eq − d1| ≤ 3°)。ロールが小さいのは車体が剛であるためか、VectorNav の姿勢推定が a_y に追従しないためかは区別できない。
* **勾配**: GNSS (全 bag の fix status 0、走行範囲は東西 18〜24 m × 南北 13〜23 m) の高度から平面を当てはめた勾配は 0.5〜4.4°、残差の標準偏差 0.24〜2.2 m。高度の雑音が走行範囲の高低差と同程度で、**試験場所の勾配は GNSS 高度からは決められない** (5.5 m/s 設定の bag は高度の幅 5.9 m で漂いが大きい)。VectorNav の姿勢の走行中の中央値は roll・pitch とも |値| ≤ 0.5° (`out/s4_attitude.csv`、取り付け誤差を含む) で、顕著な傾斜は読み取れない。横方向の傾斜 (カンバー) が 1° あっても重力成分は 0.17 m/s² で、左右差 1〜2 m/s² の説明にはならない (推測)。

## 5. 閉ループ同定値との差

§0.4 の表を参照。要点:
* 並進の T・K は閉ループとほぼ一致 (T 0.24 → 0.21〜0.27、K 0.99 → 0.98)。新しい点は **勾配制限 (加速 3.95、減速 4.06 m/s²、速度依存あり) があること** と、FOPDT だけでは大きな速度変化を表せないこと。閉ループの周回では速度変化が小さかったので FOPDT で足りていた。
* 操舵 δ_eq は K が 1.07 → 0.96 (−10 %)。ただし今回は直進時のヨーの偏り (右向き) があり、オフセットを入れない場合の K は 0.94 (−12 %)。T・L+T は同程度。閉ループでは舵角の振幅が小さく (R1 は 0.08 rad まで)、非線形性・飽和・オフセットの影響が入らなかった可能性がある。
* d1 は閉ループの R1+B1 プール (K 0.86、R² 0.46) より、振幅の大きい今回 (K 1.04、R² 0.95) の方が信頼できる。B1 のみの閉ループ値 (L 0.06、T 0.25、K 1.05) と整合する。

## 6. 注意点・疑問点

1. **データ**: 手動操縦で 6 本とも約 70 s。停止からの全開加速は設定ごとに 1〜2 回のみ (設定 5.5 と 6.0 は階段状の指令で全開加速が無い)、制動は計 28 回。直進の定常区間は 0.9〜7 s と短く、旋回が大半。5.0 設定の小ステップは無し。全 bag で `/caster_data` は他より 1.1〜3.9 s 遅れて始まる (d0 = 0 の停止中で影響なし)。
2. **勾配制限のモデルの識別**: M2 と M2p (計画機 5.0 固定) の RMSE 差は小さい (0.135 vs 0.153)。制動は M2 が明確によい (0.092 vs 0.169) が、加速は同等 (0.152 vs 0.145)。L は 0 (下限) で同定不能。K=0.965 (M2) は定常 K 0.98 より少し低い (遷移部の当てはめの偏り)。論文に載せる K は 0.98 (定常) を推奨。
3. **K の速度依存** (定常 K 0.985 → 0.959) は 6.0 設定の区間が 1 つ (430 点) のみ。最高速度は設定 6.0 でしか見られず「5.8 m/s 以上」。
4. **直進時の右向きヨー偏り** (gz = −0.09 rad/s、δ_eq −1.1°): 全 bag で一貫。停止時バイアスとは別物。原因不明 (推測)。操舵 0 の直進が短く (計 5 s 程度) 数が少ない。この偏りが左右の a_y,kin の非対称 (左 2.2〜3.0 vs 右 3.4〜5.1 m/s²) と操舵ゲインの左右差 (K_left 0.83 vs K_right 1.13) の原因と思われる。
5. **a_y は制限則 3.5 m/s² を超える**: 右旋回で 4.2〜5.8 m/s² (a_kin、1 s 平均)。制限則は指令側の制限であり実車の限界ではない。この a_y では滑り・ロールの条件を破っておらず、限界は未確認。
6. **d1 が d0 より大きい** (高速の定常旋回で d1 7〜9° vs d0 4〜6°) ことと、**駆動輪の左右速度差が実際のヨーの半分以下** (5〜6 m/s の右旋回) は、足回りの制御構造 (caster の PID・プリロード) を理解する必要がある疑問点。
7. **d1 の静止時の読み**は +0.7〜+1.3° で 0 でない (直進オフセット補正済みのはず)。a_geo はこの分 (5 m/s で約 0.6 m/s²) の誤差を含む。生の d1 を使う仕様で計算したので注意。
8. **シミー** (d1 の ≈9 Hz の振れ) は旋回中に速度とともに増える (標準偏差 0.2° → 1.3°)。gz は 20 Hz で周波数を出せない。
9. **ロール・ピッチ**は VectorNav の orientation から (走行中の中央値からのずれ)。IMU が 90° 回して付いているため、オイラー角の roll/pitch は車両の pitch/roll。a_y との相関が弱く、ロールが小さい理由 (剛性 / 推定) は区別できない。
10. **勾配**: GNSS 高度の雑音が大きく決められない (§4)。
11. **chassis_driver の yaml との差**: リポジトリの `lateral_acc_max` 3.0 (車両側 3.5)、`linear_max.vel` 5.5 (これらの bag は 6.0 まで出ている)。実機の設定値は yaml と異なる。
12. 5.0 m/s 設定の小ステップと、5.5・6.0 設定の全開加速 (停止から設定値へ一気) は無い。必要なら追加走行が要る。
